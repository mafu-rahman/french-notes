| Subject | ==Reflexive Pronoun== | English Idea          |
| ------- | --------------------- | --------------------- |
| je      | me / m'               | myself                |
| tu      | te / t'               | yourself              |
| il      | se / s'               | himself / itself      |
| elle    | se / s'               | herself / itself      |
| nous    | nous                  | ourselves             |
| vous    | vous                  | yourself / yourselves |
| ils     | se / s'               | themselves            |
| elles   | se / s'               | themselves            |


| Subject | Conjugation        | English                       |                                |
| ------- | ------------------ | ----------------------------- | ------------------------------ |
| je      | je m'appelle       | my name is / I call myself    |                                |
| tu      | tu t'appelles      | your name is                  |                                |
| il      | il s'appelle       | his name is                   |                                |
| elle    | elle s'appelle     | her name is                   |                                |
| nous    | nous nous appelons | our names are                 | note the single 'l'            |
| vous    | vous vous appelez  | your name is / your names are | note the single 'l'            |
| ils     | ils s'appellent    | their names are               | pronounced the same as appeler |
| elles   | elles s'appellent  | their names are               | pronounced the same as appeler |
