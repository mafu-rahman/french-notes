# Formation of Plurals

In French, nouns can be singular or plural.

The plural usually affects:

1. the **article**: le/la/un/une -> les/des
2. the **noun**: chat -> chats
3. the **adjective**: petit -> petits

---

## Basic Rule: Add -s

Most nouns become plural by adding **-s**.

| Singular | Plural | English |
|---|---|---|
| un chat | des chats | cats |
| une maison | des maisons | houses |
| le livre | les livres | books |
| la table | les tables | tables |

The final **-s** is usually silent.

Examples:

- un chat -> des chats
- une fille -> des filles
- le professeur -> les professeurs

---

## Articles in the Plural

| Singular | Plural |
|---|---|
| le | les |
| la | les |
| l' | les |
| un | des |
| une | des |

Examples:

- le garçon -> les garçons
- la fille -> les filles
- l'étudiant -> les étudiants
- un livre -> des livres
- une table -> des tables

---

## Nouns Ending in -s, -x, or -z

If a singular noun already ends in **-s**, **-x**, or **-z**, it usually does not change in the plural.

| Singular | Plural | English |
|---|---|---|
| le pays | les pays | countries |
| le prix | les prix | prices |
| le nez | les nez | noses |
| la voix | les voix | voices |

The article shows the plural.

---

## Nouns Ending in -au, -eau, -eu

Many nouns ending in **-au**, **-eau**, or **-eu** add **-x**.

| Singular | Plural | English |
|---|---|---|
| le bureau | les bureaux | offices / desks |
| le gâteau | les gâteaux | cakes |
| le bateau | les bateaux | boats |
| le jeu | les jeux | games |
| le cheveu | les cheveux | hairs |

Common exception:

- le pneu -> les pneus
- bleu -> bleus

---

## Nouns Ending in -ou

Most nouns ending in **-ou** follow the basic rule and add **-s**.

| Singular | Plural | English |
|---|---|---|
| le trou | les trous | holes |
| le clou | les clous | nails |

Seven common **-ou** nouns are exceptions and add **-x**.

| Singular | Plural | English |
|---|---|---|
| le bijou | les bijoux | jewels / jewellery |
| le caillou | les cailloux | pebbles |
| le chou | les choux | cabbages |
| le genou | les genoux | knees |
| le hibou | les hiboux | owls |
| le joujou | les joujoux | toys |
| le pou | les poux | lice |

Memory tip: **bijou, caillou, chou, genou, hibou, joujou, pou** take **-x**.

---

## Nouns Ending in -al

Many nouns ending in **-al** change to **-aux**.

| Singular | Plural | English |
|---|---|---|
| le journal | les journaux | newspapers |
| l'animal | les animaux | animals |
| l'hôpital | les hôpitaux | hospitals |

Common exceptions add **-s**:

| Singular | Plural | English |
|---|---|---|
| le festival | les festivals | festivals |
| le carnaval | les carnavals | carnivals |
| le bal | les bals | dances / balls |

---

## Nouns Ending in -ail

Most nouns ending in **-ail** add **-s**.

| Singular | Plural | English |
|---|---|---|
| le détail | les détails | details |
| le chandail | les chandails | sweaters |

Some common **-ail** nouns change to **-aux**.

| Singular | Plural | English |
|---|---|---|
| le bail | les baux | leases |
| le corail | les coraux | corals |
| l'émail | les émaux | enamels |
| le soupirail | les soupiraux | basement windows / vents |
| le travail | les travaux | work / works |
| le vantail | les vantaux | door leaves / panels |
| le vitrail | les vitraux | stained-glass windows |

---

## Compound Nouns

Compound nouns often use hyphens. Their plural depends on the parts of the compound.

### Noun + Preposition + Noun

When a compound noun is made of:

**noun + preposition + noun**

usually only the **first noun** becomes plural.

| Singular | Plural | English |
|---|---|---|
| un arc-en-ciel | des arcs-en-ciel | rainbows |

In **arc-en-ciel**, only **arc** becomes plural.

### Noun + Noun or Noun + Adjective

When both parts describe the thing, both parts often become plural.

| Singular | Plural | English |
|---|---|---|
| un chou-fleur | des choux-fleurs | cauliflowers |
| un chef-lieu | des chefs-lieux | administrative centers |

### Grand + Noun

With family words like **grand-père** and **grand-mère**, both parts become plural.

| Singular | Plural | English |
|---|---|---|
| un grand-père | des grands-pères | grandfathers |
| une grand-mère | des grands-mères | grandmothers |

---

## Adjectives Also Agree

When a noun is plural, its adjective usually becomes plural too.

| Singular | Plural |
|---|---|
| un petit livre | des petits livres |
| une grande maison | des grandes maisons |
| le chat noir | les chats noirs |
| la robe rouge | les robes rouges |

See [[Adjectives and Agreement]] for the full adjective rules.

## Common Irregular Plurals

| Singular | Plural | English |
|---|---|---|
| monsieur | messieurs | gentlemen / sirs |
| madame | mesdames | ladies / madams |
| mademoiselle | mesdemoiselles | young ladies / misses |
| l'oeil | les yeux | eyes |

## Common Mistakes

❌ les chat  
✅ les chats

❌ des maison  
✅ des maisons

❌ le livres  
✅ les livres

❌ des bureau  
✅ des bureaux

❌ les journal  
✅ les journaux

❌ des bijous  
✅ des bijoux

❌ des arc-en-ciels  
✅ des arcs-en-ciel

---

## Quick Pattern Summary

| Ending | Plural Pattern | Example |
|---|---|---|
| most nouns | add -s | chat -> chats |
| -s, -x, -z | no change | prix -> prix |
| -au, -eau, -eu | add -x | bureau -> bureaux |
| most -ou nouns | add -s | trou -> trous |
| 7 common -ou exceptions | add -x | bijou -> bijoux |
| many -al nouns | -al -> -aux | journal -> journaux |
| some -ail nouns | -ail -> -aux | travail -> travaux |
| noun + preposition + noun | first noun plural only | arc-en-ciel -> arcs-en-ciel |
