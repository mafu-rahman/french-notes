# Object Pronouns

Object pronouns replace nouns that receive the action of a verb.

English examples:

- I see **Marie**. -> I see **her**.
- I read **the book**. -> I read **it**.

---

## Direct Object Pronouns

Direct objects answer **who?** or **what?**

| French | English |
|---|---|
| me / m' | me |
| te / t' | you |
| le / l' | him / it |
| la / l' | her / it |
| nous | us |
| vous | you |
| les | them |

Examples:

- Je vois Marie. -> Je **la** vois.
- Tu lis le livre. -> Tu **le** lis.
- Il aime les films. -> Il **les** aime.

---

## Indirect Object Pronouns

Indirect objects often answer **to whom?** or **for whom?**

| French | English |
|---|---|
| me / m' | to me |
| te / t' | to you |
| lui | to him / to her |
| nous | to us |
| vous | to you |
| leur | to them |

Examples:

- Je parle à Marie. -> Je **lui** parle.
- Elle téléphone à son père. -> Elle **lui** téléphone.
- Nous parlons aux étudiants. -> Nous **leur** parlons.

---

## Position

In simple tenses, the object pronoun goes **before the conjugated verb**.

- Je **le** vois.
- Tu **m'**écoutes.
- Elle **nous** parle.

With two verbs, it usually goes before the infinitive.

- Je veux **le** voir.
- Tu peux **me** parler.
- Nous allons **les** aider.

---

## Negative

Put **ne...pas** around the object pronoun and verb.

- Je ne le vois pas.
- Elle ne lui parle pas.
- Nous ne les comprenons pas.

---

## Common Mistakes

❌ Je vois le.  
✅ Je le vois.

❌ Je parle à lui.  
✅ Je lui parle.

❌ Je veux le voir pas.  
✅ Je ne veux pas le voir.
