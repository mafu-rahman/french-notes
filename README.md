# French Notes

This repository is my personal French learning vault. It contains polished study notes, weekly class notes, vocabulary, grammar references, verb conjugations, and quick revision material.

The notes are written in Markdown and are organized for use in Obsidian.

---

## Structure

| Folder | Purpose |
|---|---|
| `01 - Fundamentals` | Pronunciation, alphabet, accents, and basic sounds |
| `02 - Grammar` | Articles, pronouns, nouns, questions, negation, possession, adjectives, adverbs, and comparisons |
| `03 - Verbs` | Essential verbs, regular verb groups, irregular verbs, and reflexive verbs |
| `04 - Vocabulary` | Topic-based vocabulary lists |
| `05 - Conversation` | Greetings, introductions, questions, classroom phrases, and simple dialogues |
| `06 - Tenses & Moods` | Present tense, future proche, imperative, and passé composé |
| `07 - Resources` | Quick references, roadmap, reminders, and study priorities |
| `_ Classes with Anish` | Raw weekly class notes, screenshots, images, exercises, and lesson material |

---

## Workflow

Weekly class notes are first added to `_ Classes with Anish`.

After class, the raw notes are reviewed and the important material is moved into the organized main notes:

1. Grammar concepts go into `02 - Grammar`.
2. Verb patterns and conjugations go into `03 - Verbs`.
3. Vocabulary goes into `04 - Vocabulary`.
4. Speaking patterns and useful phrases go into `05 - Conversation`.
5. Broad reminders or study strategy go into `07 - Resources`.

The raw weekly notes are kept as source material.

## Current Focus

The vault is currently focused on beginner French:

- pronunciation and spelling basics
- articles and noun gender
- subject and object pronouns
- regular verb patterns
- essential irregular verbs: `être`, `avoir`, `aller`, `faire`
- question formation
- negation
- reflexive verbs
- everyday vocabulary and simple conversation

---

## Using Codex With This Repo

When processing a new weekly class note:

1. Read the latest file in `_ Classes with Anish`.
2. Identify new grammar, verb, vocabulary, and conversation material.
3. Merge each topic into the correct organized note.
4. Add examples, common mistakes, and practice when useful.
5. Keep explanations beginner-friendly.
6. Leave the raw weekly note unchanged unless cleanup is explicitly requested.

The goal is not to copy the class notes directly, but to turn them into reusable study material.
