# 🔊 Vowel Combinations

When vowels appear together, they create new sounds. Master these patterns.

---

## 🔤 Two-Vowel Combinations

### ou = OO (like "book")
- **vous** = VOO (you formal/plural)
- **tour** = TOUR (tower/tour)
- **souris** = soo-**REE** (mouse)

### ai = AY (like "say")
- **je vais** = zhuh **VAY** (I go)
- **maison** = may-**ZOHN** (house)
- **faire** = **FAIR** (to do)

### ei = AY (same as ai)
- **beige** = **BAZH** (beige)
- **treize** = **TREZ** (thirteen)

### ei = EH (alternate)
- **seize** = **SEZ** (sixteen)
- Sometimes **ei** sounds like **ay**, sometimes like **eh**—listen to native speakers

### oi = WAH (like "swat")
- **moi** = **MWAH** (me)
- **roi** = **RWAH** (king)
- **trois** = **TWAH** (three)

### oy = WAH (same as oi)
- **voyage** = vwah-**YAZH** (trip)
- **joyeux** = zhwah-**UH** (joyful)

### au = OH (like "go")
- **eau** = **OH** (water)
- **beau** = **BOH** (beautiful)
- **Claude** = **KLOHD** (name)
- **au** = **OH** (to the)

### eu = UH (like "blur", rounded)
- **deux** = **DUH** (two)
- **peur** = **PUR** (fear)
- **bleu** = **BLUH** (blue)
- **peu** = **PUH** (little)
- **fleuve** = **FLUHR** (river)

### œu = UH (same as eu)
- **peur** = **PUR** (fear)
- **cœur** = **KUR** (heart)
- **sœur** = **SUR** (sister)

### ie = EE or YEH
- **vieil** = **VYEY** (old)
- **pied** = **PYAY** (foot)
- **client** = klee-**YON** (client)

### ui = WEE
- **lui** = **LWEE** (him/to him)
- **fruit** = **FWEE** (fruit)
- **suite** = **SWEET** (following)

---

## 🔊 Three+ Vowel Combinations

### iau = YOH
- **travail** = trah-**VAH-yuh** (work)
- **baille** = **BAH-yuh** (bucket)

### eau = OH
- **eau** = **OH** (water)
- **beau** = **BOH** (beautiful)
- **bureau** = boo-**ROH** (office)

### oi + vowel = WA + (vowel sound)
- **oie** = **WAH** (goose)
- **voie** = **WAH** (way/path)

## 🎯 Nasal Vowels (Revisited)

When vowels are followed by **n** or **m** (and NOT another vowel), they become nasal.

### -an, -en, -am, -em = AHN (nasal a)
- **dans** = **DAHN** (in)
- **enfant** = ahn-**FAHN** (child)
- **temps** = **TAHN** (time)
- **exemple** = egg-**ZAHM-pluh** (example)

### -in, -im, -ein, -ain, -ien, -aim = UNG (nasal e/i)
- **vin** = **VUNG** (wine)
- **pain** = **PUNG** (bread)
- **faim** = **FUM** (hunger)
- **bien** = **BYUNG** (well)
- **parfum** = par-**FUM** (perfume)

### -on, -om = OHN (nasal o)
- **bon** = **BOHN** (good)
- **mon** = **MOHN** (my)
- **téléphone** = tay-lay-**FOHN** (telephone)
- **combien** = kohm-**BYUNG** (how much)

### -un, -um = UNG (nasal u)
- **un** = **UNG** (a/one)
- **quelqu'un** = kel-**KUH** (someone)
- **parfum** = par-**FUM** (perfume)

---

## ⚠️ Key Rule: Non-nasal vs Nasal

**Vowel + N/M at end or before consonant = NASAL**
- **on** = nasal (final n)
- **onze** = nasal (n before z)
- **onde** = nasal (n before d)

**Vowel + N/M + another vowel = NOT nasal**
- **onde** = NOT nasal if followed by another vowel (like "onze" where z is consonant)
- **onne** (in "bonne") = the first one is nasal, second is not

Actually, let me clarify:
- **bonne** = **BON** (good, feminine)—the nasal **on**, then regular **nuh**
- **une** = **OON** (one, feminine)—nasal **un**, then silent e
