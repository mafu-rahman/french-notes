# Reflexive Verbs

Reflexive verbs show that the subject does the action to itself.

English examples:

- I wash myself.
- She wakes up.
- We get dressed.

In French, reflexive verbs use a reflexive pronoun.

---

## Reflexive Pronouns

| Subject | Reflexive Pronoun | English Idea          |
| ------- | ----------------- | --------------------- |
| je      | me / m'           | myself                |
| tu      | te / t'           | yourself              |
| il      | se / s'           | himself / itself      |
| elle    | se / s'           | herself / itself      |
| nous    | nous              | ourselves             |
| vous    | vous              | yourself / yourselves |
| ils     | se / s'           | themselves            |
| elles   | se / s'           | themselves            |

---

## Example: Se Lever

**se lever** = to get up

| Subject | Conjugation |
|---|---|
| je | me lève |
| tu | te lèves |
| il / elle / on | se lève |
| nous | nous levons |
| vous | vous levez |
| ils / elles | se lèvent |

---

## Example: S'appeler

**s'appeler** = to be called / to call oneself

This verb is semi-irregular: it uses double **l** in most forms, but not in **nous** and **vous**.

### Affirmative

| Subject | Conjugation        | English                       |                                |
| ------- | ------------------ | ----------------------------- | ------------------------------ |
| je      | je m'appelle       | my name is / I call myself    |                                |
| tu      | tu t'appelles      | your name is                  |                                |
| il      | il s'appelle       | his name is                   |                                |
| elle    | elle s'appelle     | her name is                   |                                |
| nous    | nous nous appelons | our names are                 |                                |
| vous    | vous vous appelez  | your name is / your names are |                                |
| ils     | ils s'appellent    | their names are               | pronounced the same as appeler |
| elles   | elles s'appellent  | their names are               | pronounced the same as appeler |

The **nous** and **vous** forms use one **l**:

- nous nous appelons
- vous vous appelez

### Negative

| Subject | Negative |
|---|---|
| je | je ne m'appelle pas |
| tu | tu ne t'appelles pas |
| il | il ne s'appelle pas |
| elle | elle ne s'appelle pas |
| nous | nous ne nous appelons pas |
| vous | vous ne vous appelez pas |
| ils | ils ne s'appellent pas |
| elles | elles ne s'appellent pas |

### Questions

| French | English |
|---|---|
| Est-ce que je m'appelle...? | Am I called...? |
| T'appelles-tu...? | Are you called...? |
| S'appelle-t-il...? | Is he called...? |
| S'appelle-t-elle...? | Is she called...? |
| Nous appelons-nous...? | Are we called...? |
| Vous appelez-vous...? | Are you called...? |
| S'appellent-ils...? | Are they called...? |
| S'appellent-elles...? | Are they called...? |

Useful examples:

- Comment vous appelez-vous ? = What is your name? formal
- Comment t'appelles-tu ? = What is your name? informal
- Je m'appelle ___. = My name is ___.

## Example: Se Laver

**se laver** = to wash oneself

| Subject | Conjugation |
|---|---|
| je | me lave |
| tu | te laves |
| il / elle / on | se lave |
| nous | nous lavons |
| vous | vous lavez |
| ils / elles | se lavent |

Examples:

- Je me lave les mains. = I wash my hands.
- Elle se lave le visage. = She washes her face.
- Nous nous lavons le matin. = We wash in the morning.

---

## Example: Se Réveiller

**se réveiller** = to wake up / to wake oneself

| Subject | Conjugation |
|---|---|
| je | me réveille |
| tu | te réveilles |
| il / elle / on | se réveille |
| nous | nous réveillons |
| vous | vous réveillez |
| ils / elles | se réveillent |

Examples:

- Je me réveille à sept heures. = I wake up at seven o'clock.
- Tu te réveilles tôt ? = Do you wake up early?
- Ils se réveillent tard. = They wake up late.

## Negative

Put **ne...pas** around the reflexive pronoun and verb.

- Je ne me lève pas tôt.
- Elle ne se prépare pas.
- Nous ne nous couchons pas maintenant.

---

## With Two Verbs

When a reflexive verb is an infinitive, the reflexive pronoun changes to match the subject.

- Je vais me lever.
- Tu veux te préparer.
- Elle doit se coucher.
- Nous allons nous habiller.

---

## Passé Composé

Reflexive verbs use **être** in the passé composé.

- Je me suis levé.
- Elle s'est levée.
- Nous nous sommes préparés.
- Elles se sont couchées.

The past participle usually agrees with the subject.

---

## Common Mistakes

❌ Je se lève.  
✅ Je me lève.

❌ Elle me lève.  
✅ Elle se lève.

❌ Je vais se lever.  
✅ Je vais me lever.

❌ Il ne se appelle pas Marc.  
✅ Il ne s'appelle pas Marc.
