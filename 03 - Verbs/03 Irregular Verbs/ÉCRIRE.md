# ÉCRIRE

**écrire** = to write

---

## Present Tense

| Pronoun | Conjugation | English |
|---|---|---|
| j' | écris | I write |
| tu | écris | you write |
| il / elle / on | écrit | he / she / one writes |
| nous | écrivons | we write |
| vous | écrivez | you write |
| ils / elles | écrivent | they write |

---

## Examples

- J'écris une réponse.
- Elle écrit un courriel.
- Nous écrivons en français.
