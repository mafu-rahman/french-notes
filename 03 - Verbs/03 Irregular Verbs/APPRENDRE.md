# APPRENDRE

**apprendre** = to learn

It ends in **-re**, but it is irregular. It follows the same pattern as **prendre**.

---

## Present Tense

| Pronoun | Conjugation | English |
|---|---|---|
| j' | apprends | I learn |
| tu | apprends | you learn |
| il / elle / on | apprend | he / she / one learns |
| nous | apprenons | we learn |
| vous | apprenez | you learn |
| ils / elles | apprennent | they learn |

---

## Examples

- J'apprends le français.
- Tu apprends vite.
- Nous apprenons ensemble.
